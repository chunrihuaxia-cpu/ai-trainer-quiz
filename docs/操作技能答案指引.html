场景一：美妆公司流量运营行业分析

任务1：入冬换季选品 + 营销机会窗口

1.1 选品策略（4个二级类目） - 答题框架：根据表一「入冬季节历史同期爆发品类」数据，选择 GMV 增速最快 / 爆发指数最高的 4 个二级类目 - 常见高分品类：面霜、精华液、护手霜、唇部护理（冬季热门） - 理由阐述模板：

这4个品类在历史同期的爆发指数/GMV增速排名前列，属于冬季护肤刚需品类。面霜和精华液切中用户"冬季肌肤干燥"痛点，护手霜和唇部护理为季节性高频消耗品，转化率和复购率高。

1.2 营销机会窗口 - 根据图二「入冬季节历史同期 GMV 走势」，找出 GMV 峰值时间段 - 关键窗口：双十一（11月）、双十二（12月）、年货节（1月） - 理由：这些时间点 GMV 走势呈峰值，用户消费意愿最强，且平台流量倾斜大

任务2：价格区间销售计划

2.1 双十一阶段 - 根据图三「美容护肤品类价格趋势」，选择 GMV 贡献最高的价格区间 - 通常答案：100-150 元（中端价格带，双十一主力消费带）

2.2 双十二阶段 - 通常答案：55-100 元（低价清仓带）

2.3 非促销阶段 - 通常答案：155-275 元（高端价格带，正常利润）

任务3：用户痛点内容创作

3.1 "肌肤脆弱" 痛点 - 内容方向：屏障修复、温和护肤、成分科普 - 创作要点： 1. 科普类内容：解释皮肤屏障受损的原因和修复方法 2. 成分种草：推荐含神经酰胺、角鲨烷等修复成分的产品 3. 温和护肤教程：正确清洁+修复的步骤演示 4. 用户案例/前后对比（合规前提下）

3.2 "过度清洁" 痛点 - 内容方向：科学清洁、以油养肤、温和卸妆 - 创作要点： 1. 纠正误区内容：过度清洁的危害科普 2. 产品推荐：温和氨基酸洁面、卸妆油 3. 正确清洁流程教学 4. 皮肤自测：判断自己是否过度清洁

通用答题框架（所有场景适用）

数据分析类

1. 数据定位：指出图表中的关键数据点
2. 趋势判断：数据的增长/下降趋势
3. 结论推导：基于数据给出决策建议
4. 理由支撑：用数据说话，逻辑清晰

营销策略类

1. 产品策略：选品 → 定位 → 定价 → 排品（引流款/爆款/利润款）
2. 渠道策略：平台选择 + 投放节奏 + 预算分配
3. 内容策略：用户痛点 → 内容方向 → 创作形式 → 发布节奏
4. 转化策略：引流 → 激活 → 留存 → 转化 → 裂变

排品万能公式

类型 特征 作用
引流款 高点击率、低价 拉新、承接流量
爆款 高转化、中价 走量、提升GMV
利润款 高毛利、高价 高峰时段、盈利

舆情处置万能5步

  1. 接收投诉 → 2. 详细调查 → 3. 制定方案 → 4. 实施解决 → 5. 总结反馈

核心指标速记

  • 增长率 = (后期-前期) ÷ 前期 × 100%
  • 转化率 = 转化数 ÷ 观看数 × 100%
  • 留存率 = 留存数 ÷ 新用户数 × 100%
  • 曝光最大 → 短视频 | 转化最强 → 直播 | 增长最快 → 内容电商

考试须知

  • 操作技能与理论知识分别计分，两科均需 ≥60 分
  • 每题评分标准：完全正确得满分，部分正确酌情给分，明显错误 0 分
  • 答题要点：数据引用准确 + 逻辑清晰 + 策略可执行 + 语言专业
  • 考前重点复习：排品策略、私域运营5步、舆情处置5步、数据分析公式
